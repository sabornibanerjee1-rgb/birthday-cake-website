Birthday Cake Website

Files:
- index.html: the website page
- style.css: colours and layout
- script.js: animated cake, confetti, greeting and note
- birthday.mp3: your music file (copy your existing file here)

To publish on GitHub Pages:
1. Extract this ZIP on your computer.
2. In your GitHub repository, click Add file -> Upload files.
3. Upload index.html, style.css, script.js, and birthday.mp3 together.
4. Click Commit changes.
5. Open Settings -> Pages.
6. Under Build and deployment, select Deploy from a branch.
7. Choose main and /(root), then Save.
8. Wait a few minutes and open the published site link.

Important: keep the music filename exactly birthday.mp3 and make sure it is in the same folder as index.html.
